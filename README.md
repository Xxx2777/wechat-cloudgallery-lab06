# 实验6：拾光图集

本项目在实验指导书第19章“图片分享社区”基础上做了个性化与界面升级，品牌名为“拾光图集”。实现：

- 云开发初始化
- `photos` 云数据库集合
- `getOpenid` 云函数
- 画廊式首页图片列表，按上传日期倒序
- 社媒信息流：作者故事栏、点赞、帖子文案与详情入口
- 发布文案与图片，写入 `caption` 字段
- 独立“我的”页面：微信头像/昵称、作品统计、作品管理
- 自定义底部导航：首页 / 发布 / 我的
- 作品删除：云数据库记录与云存储图片同步移除
- 详情页评论：写入 `comments` 集合
- 获取用户基础信息
- 先选图、再确认发布的发布流程
- 上传图片到云存储并写入数据库
- 网格化上传历史记录
- 个人作品主页
- 作品详情页
- 下载图片到本地相册（含相册权限引导）
- 分享给好友
- 全屏预览
- 下拉刷新与加载骨架
- 个人主页作品/获赞数据

## 使用步骤

### 1. 导入项目

在微信开发者工具中选择“导入项目”，目录选择本文件夹，AppID 使用你自己的小程序 AppID（云开发不支持游客 AppID）。如果导入时没有自动读取，请把 `project.config.json` 中的 `appid` 改成自己的 AppID。

确认开发者工具顶部已经显示云开发环境。若账号下有多个云环境，把 `app.js` 顶部 `cloudEnv` 改成你的云环境 ID；只有一个环境时保持空字符串即可。

### 2. 创建数据库

进入“云开发控制台 → 数据库”，创建集合：

`photos`

创建集合：

`comments`

建议按实验要求设置为：所有用户可读；写入权限按课程实验要求配置。如果开发者工具提示权限不足，再临时调整为适合测试的权限。

`comments` 同样设置为“所有用户可读，仅创建者可写”，评论功能即可正常工作。

### 3. 部署云函数

右键：

`cloudfunctions/getOpenid`

选择“上传并部署：云端安装依赖”。

### 4. 测试

1. 编译项目，进入首页。
2. 点击“上传图片”。
3. 允许获取微信用户基础信息。
4. 选择一张图片上传。
5. 在云开发控制台确认：云存储出现图片，`photos` 出现对应记录。
6. 返回首页，检查图片列表。
7. 点击头像，检查个人主页。
8. 点击图片，检查图片详情。
9. 测试下载、分享、全屏预览。

## 数据库字段

每次上传写入：

- `photoUrl`：云存储 fileID
- `avatarUrl`：用户头像
- `country`：国家
- `province`：省份
- `nickName`：昵称
- `addDate`：上传日期

云数据库还会自动生成 `_id`、`_openid` 等字段。
